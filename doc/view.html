Interface: DOM #

DOM #

Lightweight DOM-like interface for runtime view attachment and ownership.
A DOM can be appended into the view tree, moved, and destroyed from its owner.

dom.ref #

Reference name for this node (for lookup / debugging).

  • @get ref: string

dom.metaView #

The "meta" view (mount point) associated with this DOM node.

  • @get metaView: View

dom.owner #

The owner ViewController that manages this DOM node.

  • @get owner: ViewController

dom.appendTo(parent) #

Append this node as a child of the given parent.

  • @param parent: View Target parent view.
  • @return View The same view for chaining.

dom.afterTo(prev) #

Insert this node after an existing sibling.

  • @param prev: View The sibling after which this node will be inserted.
  • @return View The same view for chaining.

dom.destroy(owner) #

Destroy this node from its logical owner (e.g. a ViewController).

  • @param owner: ViewController The controller / owner that manages this DOM node.
  • @return void

Class: View #

View #

Base class for all visual nodes.
A View participates in:

  • The scene tree (parent/child, prev/next sibling, etc.).
  • Layout (size, alignment, margins, etc.).
  • Style (color, border, background, etc.).
  • Input and interaction events (mouse, touch, keys, gestures).
  • Rendering and visibility.
    View is also an event emitter (Notification<UIEvent>) and implements a DOM-like API.
  • @extends Notification<UIEvent>
  • @implements DOM

view.position #

Final resolved position in layout coordinates.
⚠️ Runtime-synced (render-thread updated):
This value is updated from the rendering thread.
If accessed during active rendering, x and y may come from slightly
different frame moments.
For most use cases, this value is sufficiently accurate,
but precision-critical code should not assume atomic consistency.

  • @get position: Vec2
  • @safe rt — updated by the render thread; may not always be atomically consistent.

view.layoutOffset #

Layout offset from parent content origin.

  • @get layoutOffset: Vec2
  • @safe rt — updated by the render thread; may not always be atomically consistent.

view.layoutSize #

Final resolved layout size.
For Box-like views: border + padding + content + margin.

  • @get layoutSize: Vec2
  • @safe rt — updated by the render thread; may not always be atomically consistent.

view.clientSize #

Client (inner) size in local coordinates.

  • @get clientSize: Vec2
  • @safe rt — updated by the render thread; may not always be atomically consistent.

scrollview.beginDrag(pos) #

Begin a drag interaction.
Should be called when pointer/touch press starts.
The position must be in the same coordinate space for all subsequent drag() calls.
This will:

  • Stop any ongoing momentum/animation
  • Start tracking movement
  • Prepare velocity calculation

    • @param pos: Vec2

    • @return void


scrollview.drag(pos) #

Continue dragging.
Should be called on every pointer/touch move after beginDrag().
The position must be absolute and continuous (not delta).
Scroll offset will be updated based on the movement distance
between this position and the previous one.

  • @param pos: Vec2
  • @return void

scrollview.endDrag() #

End the drag interaction.
Should be called when pointer/touch is released.
This will:

  • Compute drag velocity
  • Start momentum scrolling if enabled
  • Apply snap/catch logic if configured

    • @return void


scrollview.wheel(delta) #

Apply wheel/trackpad scrolling.
Delta is a scroll distance in pixels:
delta.y > 0 → scroll down
delta.y < 0 → scroll up
Typically called from:

  • Mouse wheel
  • Trackpad scroll
  • Keyboard-triggered scroll simulation
    This does not start a drag session and can be used independently.

    • @param delta: Vec2

    • @return void
