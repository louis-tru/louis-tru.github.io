quark/path #

Enum: PathVerb #

PathVerb #

Path verb types

  • kMove move
  • kLine straight line
  • kQuad quadratic bezier
  • kCubic cubic bezier
  • kClose close

Enum: Cap #

Cap #

Line cap style

  • kButt no stroke extension
  • kRound adds circle
  • kSquare adds square

Enum: Join #

Join #

Line join style

  • kMiter extends to miter limit
  • kRound adds circle
  • kBevel connects outside edges

oval(rect,ccw) #

Create an oval (ellipse) path.

  • @param rect: Rect The bounding rectangle of the oval.
  • @param ccw: boolean Whether to draw counter-clockwise (CCW).
  • @return Path A new path representing the oval.

arc(rect,startAngle,sweepAngle,useCenter,close?) #

Create an arc path.

  • @param rect: Rect The bounding rectangle of the arc.
  • @param startAngle: number Start angle in radians.
  • @param sweepAngle: number Sweep angle in radians (positive = clockwise, negative = counter-clockwise).
  • @param useCenter: boolean Whether to connect the center point to form a pie shape.
  • @param close: Whether to close the path. Default is false.
  • @return Path A new path representing the arc.
  • @param close?: boolean

rect(rect,ccw?) #

Create a rectangular path.

  • @param rect: Rect The rectangle bounds.
  • @param ccw: Whether to draw counter-clockwise (default: false).
  • @return Path A new path representing the rectangle.
  • @param ccw?: boolean

circle(center,radius,ccw?) #

Create a circular path.

  • @param center: Vec2 Center of the circle.
  • @param radius: number Radius of the circle.
  • @param ccw: Whether to draw counter-clockwise.
  • @return Path A new path representing the circle.
  • @param ccw?: boolean

rrect(rect,radius) #

Create a rounded rectangle path.

  • @param rect: Rect The rectangle bounds.
  • @param radius: BorderRadius Corner radius values (can define per-corner radii).
  • @return Path A new path representing the rounded rectangle.

rrectOutline(outside,inside,radius) #

Create an outline path between two rounded rectangles (outer and inner).

  • @param outside: Rect Outer rectangle.
  • @param inside: Rect Inner rectangle.
  • @param radius: BorderRadius Corner radius values.
  • @return Path A new path representing the rounded rectangle outline.

getBoundsFromPoints(pts,ptsLen,matrix?) #

Compute the bounding region from a set of points.
Does NOT check if the matrix is an identity matrix.

  • @param pts: Vec2[] The point array.
  • @param ptsLen: number Number of points.
  • @param matrix: Optional transform matrix.
  • @return Range The computed region bounds.
  • @param matrix?: Mat

path.getEdgeLines(precision?) #

Convert curves into line segments and return all edge points.

  • @param precision: Approximation tolerance (smaller = higher precision, default = 1.0).
  • @return Vec2[] An array of Vec2 representing the edges.
  • @param precision?: number

path.getTriangles(precision?,z?) #

Triangulate the filled region of the path.

  • @param precision: Approximation tolerance (default = 1.0).
  • @param z: Optional Z value for the vertices (default = 0).
  • @return Vec3[] An array of Vec3 vertices (each triple = one triangle).
  • @param precision?: number
  • @param z?: number

path.getAASideTriangles(width,precision?) #

Generate anti-aliased side triangles and body triangles.

  • @param width: number Stroke width.
  • @param precision: Approximation tolerance (default = 1.0).
  • @return Vec3[] Array of Vec3 triangles for anti-aliased side and body rendering.
  • @param precision?: number

path.dashPath(stage,offset?) #

Convert the path into a dashed path.

  • @param stage: number[] An array of segment lengths (e.g. [dash, gap, dash, gap, ...]).
           Each value represents a **distance along the path** in the same coordinate units.
           Even indices (0, 2, 4, …) are drawn segments; odd indices are skipped segments.
  • @param offset: Optional phase offset along the path (default = 0).
  • @return Path A new path containing the dashed version.
  • @param offset?: number

path.strokePath(width,cap?,join?,miterLimit?) #

Generate a stroke path from the current shape.

  • @param width: number Stroke width.
  • @param cap: Line cap style (butt, round, square).
  • @param join: Line join style (miter, round, bevel).
  • @param miterLimit: Maximum miter ratio.
  • @return Path A new path representing the stroked outline.
  • @param cap?: Cap
  • @param join?: Join
  • @param miterLimit?: number

path.normalizedPath(precision?) #

Flatten path, convert bezier to line segments.

  • @param precision: this is the scale of the number of segments,
               the larger the value, the more segments (default is 1.0)
  • @return this The flattened path (this).
  • @param precision?: number
